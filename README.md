# e-labour apology v4

A static GitHub Pages friendly apology experience made for my twinkiee.

## Assets
- `assets/audio/hold-me-in-your-arms.mp3` is the user-supplied BGM and loops continuously after the opening click.
- The voice notes are selected from the supplied Veltino archive.
- The photos are selected from the supplied Veltino archive.

## Run
Open `index.html` directly or serve this folder with a local static server.

## GitHub Pages
All links are relative (`./...`). No backend or server routes are required.
