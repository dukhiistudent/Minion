# Mansi Panday Friendship Experience

Static GitHub Pages project built around the provided friendship story and supplied media.

## Includes
- Cute scrapbook-style visual language
- Mansi Panday opening chapter
- Shirdi Sai Baba / Roblox origin story
- Agar Tum Saath Ho as looping BGM after opening interaction
- The "are you ok?", "how are you?", "Mwah", and "love you" section
- Roblox Neighbors chaos chapter
- Distance / online sisterhood chapter
- Listening promise
- Continuously animated parametric heart
- Supplied sticker artwork used throughout
- Soft dissolve photo reveals and subtle hover motion

## Deploy
Upload the contents of this folder to a GitHub repository and enable GitHub Pages.
All asset paths are relative, so the project works under a repository subpath.
